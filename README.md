# My Current Personal Portfolio

## Chabi — Systems, Software & Quality

A playful, responsive one-page portfolio for Mmasechaba Francesca Seopa.

## Files

- `index.html` — content and page structure
- `styles.css` — the complete visual system and responsive layouts
- `script.js` — the diagnostic switcher, mobile menu and pink-mode interaction

## Run locally

You can open `dist/index.html` directly in a browser. If you prefer a local server, run one from the `dist` folder, for example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Put it on the existing GitHub Pages site

Copy the three files inside this repo to the publishing root of the repository currently serving `chabi.lol`, commit, and push. Keep the custom-domain `CNAME` file already present in that repository.
